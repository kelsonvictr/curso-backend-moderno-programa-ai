SE ALGO DER ERRADO
  "permission denied: ./mvnw" → chmod +x mvnw. Windows → mvnw.cmd test.
  "release version 21 not supported" → Java antigo; java -version.
  -Dtest no Windows → use as aspas em "-Dtest=..." ou o ▶ da IDE ao lado do teste.
  S: NullPointerException → faltou "= new CalculadoraDeMulta()" no campo.
  O: multa da Ana = 0 → calculadora ainda com equals("ALUNO") (compila e nunca bate).
  L: "cannot find symbol List" → faltou import java.util.List.
  D: "cannot find symbol enviar" → sobrou chamada antiga na Biblioteca.
  Seta digitada como → em vez de -> → não compila; hífen + maior que.
  Números de linha nos erros variam conforme onde o aluno digitou: tudo bem.
