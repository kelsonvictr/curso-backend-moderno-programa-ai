SE ALGO DER ERRADO
  "permission denied: ./mvnw" → chmod +x mvnw. Windows → mvnw.cmd test.
  "release version 21 not supported" → Java antigo; java -version.
  -Dtest no Windows/PowerShell → use as aspas em volta de "-Dtest=..." ou o ▶ da IDE.
  Ato S: NullPointerException → faltou "= new CalculadoraDeMulta()" no campo.
  Ato O: multa da Ana = 0 → calculadora ainda com equals("ALUNO") (compila e nunca bate).
  Ato L: "cannot find symbol List" → faltou import java.util.List.
  Ato D: "cannot find symbol enviar" → sobrou chamada antiga na Biblioteca.
  Seta digitada como → em vez de -> → não compila; hífen + maior que.
  Números de linha nos erros variam conforme onde o aluno digitou: tudo bem.
