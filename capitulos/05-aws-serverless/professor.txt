REGRAS QUE VOCÊ REPETE
  A chave nunca entra em arquivo, commit ou conversa com o agente.
  Comando de nuvem (deploy, remove, aws) quem roda é o aluno, nunca o agente.
  Depois que a esteira existe, ninguém faz deploy do notebook.

SE ALGO DER ERRADO
  Conta AWS "pending" / ainda ativando → aluno acompanha em dupla; não há atalho.
  Unable to locate credentials → aws configure. InvalidClientTokenId → chave errada ou apagada.
  Framework Core: 4.x → instalou a v4 (pede login). npm install -g serverless@3.
  PowerShell "execução de scripts desabilitada" → usar cmd ou Git Bash.
  artifact não encontrado → faltou ./mvnw package. permission denied ./mvnw → chmod +x mvnw.
  Internal Server Error → serverless logs -f cadastrarLivro. AccessDenied = iam; ResourceNotFound =
  nome da tabela; Task timed out after 6.00 seconds = faltou timeout: 15.
  Vercel 404 → Root Directory. CORS persiste → origem com barra no fim ou sem https.
  Actions: ./mvnw Permission denied → git update-index --chmod=+x backend/mvnw (Windows).
  UPDATE_IN_PROGRESS → dois deploys ao mesmo tempo; esperar.
  O agente rodou deploy sozinho → pare, releia a regra 1 do AGENTS.md com a turma: é conteúdo.

CINCO FRASES
  Serverless: sem pedido, sem custo.
  IaC: infra escrita se refaz; infra clicada se perde.
  IAM: cada função recebe só o que usa.
  CORS: quem bloqueia é o navegador; quem libera é a API.
  CI/CD: quem publica é a esteira, e só o que passou no teste.
