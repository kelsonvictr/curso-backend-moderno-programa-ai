# Laboratório de revisão — Cap 02
Java 21, Maven Wrapper, sem banco e sem rede em execução. Use ./mvnw test.
O projeto é independente do serviço pedidos. Não adicionar Spring, dependências,
gateway real, cobrança, framework de plugins ou tabelas.
Leia RETOMADA.md e o caso escolhido antes de planejar. Peça aprovação do plano
antes de editar. Preserve cenários de teste; se um teste documenta um defeito,
substitua a expectativa pela regra aprovada e explique a diferença.
Não exigir interface por classe nem um achado por letra ao revisar código real.
